Структура проекта:

| Название файла               | Содержание файла                           |
|------------------------------|--------------------------------------------|
| data.py                      | тестовые данные используемые в тестах      |
| tests/test_create_courier.py | файл с проверками создание курьера         |
| tests/test_get_order_list.py | файл с проверками список заказов           |
| tests/test_login_courier.py  | файл с проверками логин курьера            |
| tests/test_make_order.py     | файл с проверками создание заказа с цветом |
| conftest.py                  | фикстуры для тестов                        |
| requirements.txt             | список зависимостей для проекта            |
| allure_results               | каталог с отчетом о тестировании           |
| generators.py                | файл с генераторами                        |

### <h>1. добавляем папку с отчётом Allure к файлам. Ключ -f пригодится, если папка target указана в .gitignore:</h>

> git add -f .\target\allure-results\.</h>

### <h>2. выполняем коммит:</h>

> git commit -m "add allure report"

### <h>3. отправляем файлы в удалённый репозиторий</h>

> git push
